# Celestial Guardian

A time-bending white dragon who guards the flow of the stars. Pearl-white scales, icy blue eyes, swept silver horns, gold details, and an attached chest timepiece give it a celestial identity.

The pet bundle contains `pet.json` and `spritesheet.webp`. Its Codex v2 atlas is 1536 x 2288 pixels, with 192 x 208 cells, nine standard animations, a neutral pose, and sixteen look directions.

Animations: idle, moving right, moving left, waving, jumping, disappointed reaction, waiting for input, working with its timepiece, and thoughtful review.

Installed files are staged together at `C:\Users\amaur\.codex\pets\celestial-guardian`. The task creates and validates the pet files; it does not change the app's current pet selection.

`preview.gif` shows the greeting. `portrait.png` contains the original character reference. The `qa` folder contains the contact sheet, direction sheet, animation previews, independent review results, and validation reports. `prompts.md` records the prompt set. Artwork was created with the built-in image generator; no API/CLI fallback was used.

The adjacent `celestial-guardian.zip` is the portable pet bundle.
