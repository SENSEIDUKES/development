# R2 icon URLs

Collected 2026-10-09 from the `seihouse` bucket. All 33 objects use the bucket's verified public custom domain, `media.seihouse.org`. Object names and case are preserved.

The active Library skin uses the original Help and Search artwork and Basic Energy. EnergySun is intentionally deferred. Other artwork remains available in the existing Icons Workshop. QI yin-yang uses SENQi; the seated figure uses SENQiHead. Companion is the ally handshake, Faction the opposing fists, Storage the Story Bank, Create the navigation book, and Reward the relic card.
